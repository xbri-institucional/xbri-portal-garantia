# XBRI · Portal de Garantia — Homepage (desktop)

Homepage do Portal de Garantia com o menu principal em tela cheia.
Site estático (HTML, CSS e JS, sem build): basta servir a pasta.

- `index.html` — estrutura da página
- `assets/css/main.css` — estilos (escala 1:1 com o frame de 1640px do Figma via `--u`)
- `assets/js/main.js` — smooth scroll (Lenis), parallax e esfumaçado do header, entrada do título, menu
- `assets/video` — vídeos do header e do rodapé (H.264, sem áudio)
- Fonte Termina via Adobe Fonts (`use.typekit.net/pth2nqy.css`) e Montserrat via Google Fonts

Somente desktop nesta fase.
